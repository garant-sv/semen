# Семён

Личные проекты для Семёна.

| Папка / файл | Что это |
| --- | --- |
| `index.html` | «Семён учится» — учебная страница (одним файлом). |
| `zeleny-sad/` | **«Зелёный сад»** — детская PWA-игра: сад, огород, природные зоны России, ярмарка с задачами по математике, таблички по русскому языку, гости, задания Листика, вопросы по «Окружающему миру» 4 класса. Исходники (TypeScript + Vite), тесты и подробный README внутри. |
| `zeleny-sad/site/` | Готовая сборка игры — именно её выкладывает скрипт на сервер. |
| `deploy/zeleny-sad-install.sh` | Установка и обновление игры на сервере с nginx. |

## Обновить игру на сервере

На сервере под root:

```bash
curl -fsSL https://raw.githubusercontent.com/garant-sv/semen/main/deploy/zeleny-sad-install.sh | bash
```

По умолчанию игра ставится на `sad.kvestapp.ru` (нужна A-запись `sad` → IP сервера; HTTPS-сертификат скрипт выпускает сам). Другой адрес — `DOMAIN=sad.example.ru` перед `bash`. Скрипт трогает только папку `/var/www/zeleny-sad` и один файл `/etc/nginx/sites-available/zeleny-sad.conf`, а перед перезагрузкой проверяет `nginx -t`.

### Самообновление

После одного запуска скрипта (с версии 0.8) сервер обновляет игру сам: раз в 10 минут `/etc/zeleny-sad/site-update.sh` (cron `/etc/cron.d/zeleny-sad-update`) смотрит, изменилась ли ветка `main`, и если да, забирает только готовую сборку `zeleny-sad/site`. Качаются не архив всего репозитория (в нём ~50 МБ озвучки), а только файлы сборки по одному: что не изменилось с прошлого выпуска (обычно озвучка), берётся из него, остальное качается с докачкой и повторами, и каждый файл сверяется с его хэшем в git.

- Код из GitHub на сервере не исполняется: копируются только статические файлы (html, js, css, картинки), всё остальное отклоняется. Размер сборки не больше 50 МБ.
- nginx, сертификаты и другие сайты на сервере не трогаются: меняется только ссылка `/var/www/zeleny-sad/current`.
- Если после переключения сайт не отвечает 200, возвращается прежний выпуск, а эта версия больше не пробуется до следующего изменения `main`.
- Журнал: `/var/log/zeleny-sad/update.out`. Хранятся три последних выпуска.
- Выключить: тот же скрипт с `AUTO_UPDATE=0` перед `bash`.

Значит, после слияния PR в `main` игра на сервере обновится сама в течение 10 минут. Скрипт установки вручную нужен только при изменении настроек nginx или самого скрипта.

## Собрать игру после изменений

```bash
cd zeleny-sad
npm install
npm run check          # типы, юнит-тесты, сборка, e2e
npm run build && rm -rf site && cp -r dist site
```
