# «Зелёный сад» — паспорт проекта (для чатов проекта «Квест»)

Обновлено: 14.11.2026. Положи этот файл в файлы проекта — любой новый чат будет в курсе.

## Что это
Детская браузерная игра-сад (PWA) для 2–5 классов. Сделана для Семёна (школа 548, Москва), сейчас — тест на детях друзей.
Ребёнок будит заброшенный сад: сажает, поливает, собирает, встречает зверей, путешествует по природным зонам (огород, тундра, тайга, степь).
Учебная часть встроена в игру, по классу ребёнка:
- **Окружающий мир** — вопросы Листика (≈52 вопроса с отметкой класса 2–5).
- **Математика** — «Ярмарка урожая»: покупатели приходят раз в 8 минут с задачей (уровни по классу; 2 класс — в пределах 100).
- **Русский язык** — «Таблички у грядок»: вставить пропущенную букву (99 слов, правила по классам; во 2 классе без Ъ).
Все задания написаны заново по ФРП (edsoo.ru), без копирования учебников.

## Где что лежит
- Игра: https://sad.kvestapp.ru (поддомен квеста). Сайт квеста kvestapp.ru — отдельный проект, пока не запущен.
- Код: GitHub `garant-sv/semen` (публичный), папка `zeleny-sad/` (исходники) и `zeleny-sad/site/` (готовая сборка). Скрипт установки: `deploy/zeleny-sad-install.sh`.
- Журнал игры: `garant-sv/zeleny-sad-logs` (закрытый), файлы `days/ГГГГ-ММ-ДД.jsonl`.
- Копия на Маке: `~/Semen/green-garden-pwa` (git).
- Сервер: TimeWeb, облачный сервер main-prod-1 (там же Правление 365 и Портье).

## Как обновить сервер
В консоли TimeWeb под root:
```
curl -fsSL https://raw.githubusercontent.com/garant-sv/semen/main/deploy/zeleny-sad-install.sh | bash
```
Скрипт трогает только свой файл nginx `zeleny-sad.conf`, папку `/var/www/zeleny-sad` (хранит 3 последних выпуска), `/etc/zeleny-sad`, `/var/log/zeleny-sad` и `/etc/cron.d/zeleny-sad-journal`. Перед перезагрузкой nginx проверяет конфиг и при ошибке откатывает свою правку.

## Журнал и ежедневный разбор
- Игра шлёт обезличенные события на `/api/e`: случайный номер устройства, класс, версия, какой вопрос/слово/задача и верно ли, ошибки программы. Имя, сад, IP не сохраняются. Выключатель в Меню: «Помогать улучшать игру».
- Сервер в 00:05 складывает журнал за сутки в файл и отправляет в `zeleny-sad-logs` (deploy key с правом записи).
- Задача по расписанию «Зелёный сад: разбор журнала игры» — каждый день 10:37 МСК: разбирает журнал, открывает PR в `semen`, коротко отчитывается. Сливает PR только Андрей.

## Безопасность
CSP `default-src 'self'`, запрет встраивания (frame-ancestors none, X-Frame-Options DENY), без камеры/микрофона/геолокации, Referrer-Policy no-referrer, обычный access_log выключен. В игре нет внешних ссылок; service worker отвечает игрой на любой адрес внутри sad.kvestapp.ru.
Открытый вопрос: kvestapp.ru (кабинет квеста) сейчас публичный — ребёнок может набрать адрес вручную. Закрыть паролем можно только в конфиге квеста — ждёт решения Андрея.
