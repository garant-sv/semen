# Зелёный сад

Уютная детская игра о том, как разбудить заброшенный волшебный сад. Сделана для Семёна (10 лет) как PWA для iPhone: её можно установить на домашний экран, и после первой загрузки она работает без интернета.

> **Это новая реализация, а не восстановление старого кода.** Старые исходники найдены и изучены (см. «Аудит»), но код, графика и звуки написаны заново.

## Что есть в игре

- Один сад с шестью грядками и шестью растениями: ромашка, подсолнух, колокольчик, тюльпан, лаванда, лунный цветок. У каждого четыре заметные стадии: семечко → росток → бутон → цветок.
- Посадка, полив, рост, цветение и сбор. Каждая стадия начинается после полива.
- Помощник **Листик** и цепочка из 10 понятных заданий.
- Восстановление **мостика** и **пруда**: сцена видимо меняется. Ручей доходит до пруда, появляются кувшинки и светлячки, дымка заброшенности уходит, а сухая трава исчезает.
- Шесть украшений (фонарик, вертушка, скворечник, скамейка, пугало, цветочная арка) на шести местах. Их можно переставлять.
- Коллекция открытых растений с короткими фактами.
- **Гости сада** (с версии 0.2): божья коровка, улитка, пчела, бабочка, ёжик и лягушка заходят ненадолго. Если нажать на гостя, он даёт лепестки и попадает в коллекцию с фактом о себе. Ёжик приходит после починки мостика, лягушка живёт у наполненного пруда, пчела и бабочка прилетают к цветущим грядкам.
- **Золотые цветы**: начиная с 4-го задания любое семечко может вырасти золотым (12 %; после 8 обычных подряд золотое гарантировано). Это видно только в момент цветения. Золотой цветок даёт вдвое больше лепестков, а в коллекции считаются золотые каждого вида.
- **Доска просьб у пруда**: с 5-го задания гости просят вырастить 1–3 цветка за награду. Просьбы не кончаются, поэтому после всех заданий есть чем заняться.
- **Огород** (с версии 0.3): указатель «Огород» в правом верхнем углу сада ведёт на отдельную сцену с четырьмя грядками, сарайчиком и бочкой. Огород открывается после 8-го задания за 50 лепестков. Там растут морковка, клубника и тыква (у них свои стадии и рисунки). Гости начинают просить и овощи.
- **Природные зоны России** (с версии 0.4): вкладка «Карта» показывает зоны с севера на юг (арктическая пустыня, тундра, тайга, смешанный лес — «наш сад», степь, полупустыня) с описанием климата, растений и животных по программе «Окружающего мира» 4 класса. В тундру, тайгу и степь можно снарядить экспедицию: у каждой своя сцена, три участка земли, свои растения (морошка, карликовая берёза, ягель; брусника, кедр, черника; ковыль, тюльпан Шренка, полынь) и свои животные-гости (северный олень, песец, лемминг; белка, бурундук, бурый медведь; сайгак, суслик, степной орёл). Растение растёт только в своей зоне.
- **18 заданий Листика** (в 0.4 добавлены «Экспедиция в тундру», «Хвойный лес», «Степные просторы»). Раньше было 15: (в 0.2 добавлены «Гости сада», «Золотой цветок», «Добрый сосед», в 0.3 — «Свой огород» и «Большая тыква»).
- **День и ночь** по часам устройства: вечером сад теплеет, с 21:00 до 6:00 наступает ночь со звёздами и луной, светятся фонарики, лунный цветок, золотые растения и окно сарайчика.
- **Вопрос Листика** (прототип обучения): после каждых трёх собранных растений у Листика появляется «?». Это вопрос по «Окружающему миру» за 4 класс (29 вопросов: природные зоны России, водоёмы, формы поверхности, Солнечная система, связи в природе, охрана природы). Верный ответ даёт 5 лепестков, неверный — 1 лепесток «за старание» и объяснение, а вопрос вернётся позже. Вопросы в `src/game/quiz.ts`, их легко дополнить.
- **Значки**: 11 значков с прогрессом (вкладка «Значки» в «Коллекции»).
- **Фото сада**: «Меню → Сфотографировать сад» делает картинку 1200×1920 с датой. На iPhone открывается меню «Поделиться», на компьютере файл скачивается.
- На маленьких экранах (iPhone SE) карточка задания сама сворачивается после первого нажатия в саду.
- **Анимации**: растения покачиваются, при смене стадии растение «выпрыгивает» вверх с кольцом света; лейка наклоняется и поливает, земля темнеет от воды; семечко падает в грядку; собранный цветок выскакивает из земли, а лепестки летят к счётчику, который считает вверх; доски мостика укладываются по одной, пруд наполняется водой, по нему идёт рябь, а облака плывут. Листик моргает, покачивается и подпрыгивает, когда задание выполнено; при выполнении задания летит конфетти. Если на устройстве включено «Уменьшение движения», анимации отключаются.
- Растения **никогда не погибают**. Если долго не заходить, они просто ждут полива.
- Нет рекламы, покупок, регистрации, чатов, аналитики и сетевых запросов к сторонним сервисам.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev          # разработка: http://localhost:5173
npm run build        # сборка в dist/
npm run preview      # проверка сборки: http://localhost:4173
```

Проверить на iPhone в той же Wi-Fi-сети: `npm run build && npm run preview`, затем открыть в Safari `http://<IP-Mac>:4173`. Service worker и установка «На экран Домой» в полной мере работают только по HTTPS (или на localhost), поэтому офлайн на телефоне проверяется после публикации на HTTPS-хостинг, например GitHub Pages. Публикация не сделана: её нужно согласовать отдельно.

Установка на iPhone: Safari → «Поделиться» → «На экран „Домой“».

## Технологии и почему так

**TypeScript + Vite, без игрового движка. Сцена — SVG, интерфейс — обычный DOM.**

- Игра — пошаговая «грядочная» диорама без физики и быстрой анимации. Phaser добавил бы около 1 МБ и canvas-рендер, на котором текст и тонкие линии хуже выглядят на Retina-экране и сложнее делать доступные кнопки.
- SVG чётко масштабируется на любом iPhone, а каждую грядку можно сделать отдельной кнопкой с подписью.
- Сборка весит около 190 КБ вместе с иконками, поэтому быстро кэшируется и стабильно работает офлайн.
- Логика (`src/game/`) — чистые функции с явным временем `now`, поэтому рост, сохранения и задания легко тестировать.

Godot-проект не взят за основу: его веб-экспорт тяжёлый (WASM, десятки МБ) и плохо подходит для офлайн-PWA на iOS.

## Устройство

```
src/game/data.ts    растения, украшения, задания Листика
src/game/state.ts   правила: рост по меткам времени, полив, сбор, ремонт, украшения, задания
src/game/quiz.ts    вопросы Листика по «Окружающему миру», 4 класс
src/game/badges.ts  значки
src/game/save.ts    сохранение, запасная копия, миграции, проверка данных, экспорт/импорт
src/ui/art.ts       вся графика (SVG в коде)
src/ui/scene.ts     диорама сада
src/ui/app.ts       интерфейс: HUD, карточка Листика, листы, тосты
src/ui/sound.ts     звуки, синтезированные Web Audio
src/sw/sw-template.js  service worker (список файлов подставляется при сборке)
```

**Рост.** У растения хранятся стадия и момент полива. При каждом открытии, возврате на вкладку и каждую секунду на экране стадия пересчитывается от текущего времени. Фоновые таймеры не нужны. Одна поливка — одна стадия. Если часы устройства перевели назад, рост не ломается.

**Сохранения.** Текущая версия формата — 5. Сохранения версий 1–4 обновляются автоматически, прогресс не теряется. Сохранение в `localStorage` идёт после каждого действия и при сворачивании. Перед записью предыдущая версия копируется в запасной ключ. Повреждённые данные не стираются, а откладываются отдельно. Ошибки (нет места, хранилище запрещено) показываются баннером с кнопкой резервной копии. У каждого сохранения есть номер версии и цепочка миграций.

**Важно про iPhone.** Safari может удалить данные сайта, если его долго не открывать. Для установленной на домашний экран PWA это менее вероятно, но надёжнее время от времени делать резервную копию: «Меню → Сохранить резервную копию».

## Графика, звуки и лицензии

- **Вся графика нарисована в коде специально для этого проекта** (`src/ui/art.ts`, `src/ui/scene.ts`, `public/icons/icon.svg`): Листик, растения, украшения, мостик, пруд, фон, иконки. Сторонних изображений, стоков и эмодзи нет.
- **Звуки** синтезируются в браузере (Web Audio, `src/ui/sound.ts`). Аудиофайлов нет.
- **Шрифт** системный (`ui-rounded` на iPhone). Внешние шрифты не загружаются.
- Инструменты разработки, не входящие в сборку: Vite (MIT), Vitest (MIT), TypeScript (Apache-2.0), Playwright (Apache-2.0).
- Лицензию на сам код выбирает владелец репозитория; файл LICENSE пока не добавлен.
